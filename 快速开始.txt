简集 · 另一台电脑运行说明
============================

1. 安装 Node.js 24 或更高版本（需包含 node:sqlite 支持）。
2. 解压本压缩包到任意目录。
3. Windows 双击 start.cmd，或在命令行运行：
   node server.js
4. 浏览器打开 http://localhost:8787 即可使用。
   同一 Wi-Fi 下，手机可打开 http://电脑局域网IP:8787 。

数据默认保存在程序目录下的 data 文件夹。
如果要放到公网，可参考 README.md 的部署章节，使用云服务器 + 域名，
或用 Cloudflare Tunnel / 反向代理生成外部 HTTPS 地址。

课程表 OCR 默认使用 OCR.space，公共测试 key 可能限流；
正式使用请申请自己的 OCR_SPACE_API_KEY。
